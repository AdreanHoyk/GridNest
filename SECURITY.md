# Сообщить об ошибке

Обычные ошибки интерфейса можно описывать в Issues. Не публикуйте там личные пути, содержимое ярлыков, токены или документы. Для сообщения об уязвимости используйте приватный механизм GitHub **Report a vulnerability**, если он доступен в репозитории.

Сейчас проект не имеет цифровой подписи издателя или гарантированного срока поддержки. Скачивайте код и сборки из этого репозитория. Приложение запускает пользовательские ярлыки через оболочку Windows; добавляйте только доверенные файлы.
