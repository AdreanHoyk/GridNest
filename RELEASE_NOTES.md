## Исправление сброса настроек папок

- Воспроизведён сценарий, при котором временная ошибка чтения при запуске приводила к записи стандартных значений поверх оформления папки.
- Настройки читаются один раз, с повторными попытками и восстановлением из резервной копии.
- Если основной файл и копия недоступны или повреждены, автоматическая запись стандартных значений блокируется: исходные файлы сохраняются.
- Сохранение выполняется через временный файл и атомарную замену. Предыдущая корректная версия хранится в файле .xml.bak.
- Ошибки чтения и записи больше не скрываются: показывается уведомление в трее и создаётся settings-errors.log.

## Проверки

Проверены временная блокировка чтения, повреждённый и отсутствующий основной файл, восстановление из копии, блокировка записи и сохранение оформления после трёх отдельных запусков тестового процесса. Общие проверки приложения выполнены отдельно. Полная перезагрузка Windows в ходе проверки не выполнялась.

## Установка

Запустите GridNest-Setup.exe или обновитесь из приложения. Содержимое папок сохраняется.
