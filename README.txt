GridNest 0.14.0 — папки и файлы на рабочем столе

УСТАНОВКА
Обычный вариант: запустите GridNest-Setup.exe и нажмите «Установить / Обновить».
Можно выбрать автозапуск и запуск после установки. Настройки и файлы сохраняются.
Если старая версия открыта, завершите её через трей и повторите установку.
EXE-установщик: https://adreanhoyk.github.io/GridNest/downloads/GridNest-Setup.exe

Альтернатива — ZIP:
Распакуйте ZIP целиком. В PowerShell из распакованной папки:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
Права администратора не нужны. Bypass действует только для этого запуска.
Для установки без автозапуска добавьте -NoStartup.
Обновление: сначала выйдите из GridNest через меню трея.

ИСПОЛЬЗОВАНИЕ
Режим «Файлы»: оригиналы файлов и папок перемещаются внутрь панели
и исчезают с прежнего места, в том числе с рабочего стола.
Режим «Ярлыки»: для внешнего файла создаётся ссылка, оригинал остаётся.
Ярлыки с рабочего стола перемещаются в обоих режимах; прочие внешние ярлыки
в режиме «Ярлыки» копируются. Режим выбирается в настройках папки.
Между панелями значки перемещаются. Смена режима не преобразует старые файлы.
Внутри панели перетаскивайте в нужную ячейку: порядок сохраняется.
На занятой ячейке значки меняются местами. При совпавшем имени файл не затирается.
Тяните маркер ⠿ внизу или название папки для перемещения; правый угол — размер.
Размер меняется целыми ячейками. Положение привязывается к общей сетке 16 DIP.
Рамка показывает место после отпускания мыши. Esc отменяет перенос, Ctrl+Z — последнее перемещение или изменение размера. В настройках приложения выберите свободное наложение или отступ 0, 8 либо 16 DIP. Закрепить панели можно в трее.
Прокрутка не появляется из-за пустых служебных ячеек.
Масштаб: ползунок в настройках или Ctrl + колесо мыши (28–128 px).
Число ячеек сохраняется, панель подстраивается под масштаб.

ЦВЕТ ПОДЛОЖКИ
Правый щелчок по фону → «Цвет подложки…».
Выберите образец, введите #RRGGBB или откройте палитру Windows.
Нажмите «Применить». Цвет сохраняется отдельно для каждой папки.
Непрозрачность задаётся независимо в «Размер и оформление…».

АНИМАЦИИ И ПРОКРУТКА
Прокрутка заканчивается над отдельной нижней зоной изменения размера.
Число ячеек сохраняется, высота подложки при обновлении увеличивается на 24 DIP.
Наведение увеличивает значок на 8%, нажатие даёт короткий отклик.
Угол подсвечивается при наведении; папки появляются за 160 мс.
Меню фона → «Анимации значков и панелей» включает/отключает эффекты для папки.
При системном отключении анимаций Windows эффекты тоже отключаются.

ТЕМЫ И УПРАВЛЕНИЕ ЧЕРЕЗ ТРЕЙ
В меню фона или трея откройте «Настройки приложения…».
Доступны светлая, тёмная и системная тема. Меняются окна, меню и оформление
трея; цвета подложек папок сохраняются. Выбор сохраняется между запусками.
Все панели скрыты из панели задач Windows, отдельной «Работы» там больше нет.
Общий значок GridNest находится в трее (возможно, внутри ^).
Подменю «Папки» содержит все группы: щелчок показывает или скрывает выбранную.
Компактные точки переноса и тонкие линии изменения размера занимают нижнюю
зону высотой всего 12 DIP. Прокрутка до неё не доходит.

МЕНЮ
Правый щелчок по значку: открыть, переименовать или показать в Проводнике.
Правый щелчок по фону: настройки, цвет, создание, переименование,
архивирование, поиск, выравнивание всех папок и другие параметры.
Поиск: Ctrl+F при активной панели или меню трея. Enter открывает выбранное,
Escape закрывает поиск. Ищется имя значка и/или группы, без учёта регистра.
Трей рядом с часами (возможно, внутри ^): показать/скрыть все папки, поиск,
создать папку, выровнять, открыть архив, выйти. Двойной щелчок показывает панели.

ХРАНЕНИЕ
Настоящие папки: системные Документы\GridNest (учитывается OneDrive).
Программа и настройки: .app. Порядок: скрытый .gridnest-order.xml в каждой группе.
Удаление группы сохраняет её в .archive; окончательное удаление не выполняется.
Для возврата переместите папку из архива в GridNest и перезапустите приложение.

ОГРАНИЧЕНИЯ
Ориентировано на Windows 11; проверено в одной Windows-среде. Для всех DPI,
версий Windows и мониторов совместимость не подтверждена. Поддерживается
основная рабочая область экрана; полноэкранные приложения и команда Windows
«Показать рабочий стол» могут скрывать панели. Размытия подложки нет.
Программа не подписана цифровым сертификатом. Не требует Rainmeter/плагинов,
не отправляет сетевых запросов, не собирает телеметрию.

УДАЛЕНИЕ
Выход через трей; удалите GridNest.lnk из shell:startup и меню Пуск, затем .app.
Папки с ярлыками и архив можно сохранить.

Оформление нескольких папок
В меню папки доступны «Скопировать оформление», «Вставить оформление…» и «Применить оформление к другим…». В настройках папки также есть кнопка «Применить к другим папкам…». Выберите получателей и параметры. По умолчанию переносится цвет, прозрачность и цвет названия. Масштаб значков и размер выбираются отдельно. Стиль для новых папок можно сохранить галочкой. Ctrl+Z отменяет массовое изменение.

Добавлены темы значков «Мягкое стекло» и «Пастель» с предпросмотром. Тема переносится через применение оформления и сохраняется для новых папок.

Цвет и прозрачность показываются на папке во время настройки. Сохранение подтверждает изменения; Отмена, Esc и закрытие возвращают прежний вид. При массовом применении прозрачность выбирается отдельно.

Настройки разделены на секции. В окне применения оформления список папок прокручивается внутри рамки. Кнопки и счётчик выбранных папок остаются внизу окна. В настройках папки доступны оформление, значки, размер, способ добавления файлов и режим поверх окон.

В настройках папки раздел «Обводка» позволяет выбрать цвет, толщину 0–8 px и свечение 0–100%. Изменения показываются на папке сразу. Для копирования используйте «Обводка и свечение» в окне применения оформления. Нулевые значения отключают соответствующий эффект.

Компактные настройки
Команды находятся в подменю «Папка», «Оформление» и «Размещение». Настройки папки разделены на вкладки. В разделе «Обводка» доступны направление свечения и пульсация. Отключение анимаций папки приостанавливает пульсацию.
Папка → Убрать папку → На рабочий стол… переносит ярлыки, файлы и вложенные папки на рабочий стол текущего пользователя. Совпадающие имена получают номер. При ошибке оставшиеся объекты доступны в панели, перенос можно повторить. Служебные файлы панели сохраняются в архиве.
